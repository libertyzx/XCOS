# 回归与体积基线

> **一句话**：这里记录**当前基准的数值**（功能 20 条用例 / 固件大小 / 关键路径耗时）。改代码后如果数值**该变**（例如加了功能），
> 就更新这里并写清"为什么变"；如果**不该变却变了**，说明有意外，要先查清楚。

> **机器口径**：`Tests/baseline.json`（脚本读写）；**本文件**是"人读说明 + 数值台账"。
> **更新方式**：`powershell -File Tests/run_size.ps1 -WriteBaseline` → 更新 json；把**关键数字与"为什么变"写进本文件**。
> `Docs/CHANGELOG.md` **只记**「改了什么 · 为什么 · 对使用者什么影响」（大白话，不贴数值），数值以本文件为准。

## 3. 镜像级基线（`Examples/CortexM3_Test`，12 个任务）

| 配置 | Code | RO-data | RW-data | ZI-data |
| --- | --- | --- | --- | --- |
| `default`（无开关） | **8764** | 380 | 40 | **1944** |
| `stats`（仅开关 `XC_CFG_TASK_STATS=1`；统计代码由调度器主循环引用） | **8916** | 380 | **56** | **2040** |
| `diag`（**四开关全开** `ERR_HOOK`+`DEBUG_CHECK`+`TASK_STATS`+`ASSERT`；镜像副本内注入"空 `XC_Err_Hook` + 引用诊断 API"以便链接/不被死代码消除） | **9868** | 380 | **56** | **2040** |

> **2026-09-16（A17 空闲 Tick 取值纪律）**：三个配置各 **+48 B**（`default` 8716 → **8764**、`stats` 8868 → **8916**、
> `diag` 9812 → **9864**），**RO / RW / ZI 全不变 ⇒ RAM 0**；对象级 `XC_Sch.o` off 632 → **660**、diag 708 → **732**
> （其中"锁内取值（补锁）"相对"无锁捕获"再多 **8 B**/对象、**20~24 B**/镜像）。

> **2026-09-16（归位判定改造：移除任务时把节点置 `NULL` + 锁外快判 / 锁内复判）**：在 A17 基础上再 **+4 B**/镜像
> （`default` / `stats` / `diag` = **8768 / 8920 / 9868**），**RAM 0**；对象级 `XC_Sch.o` **±0**（免一条状态判定 −8、锁内复判 +8）、
> `XC_Task.o` **+4**（`HandleRemove` 多 2 次指针写）。
> 热路径实测（MDK 仿真，2 任务纯 Yield 的"让出往返"）：改造前 **436** → **438** 周期（净 **+1 周期/次让出**：免状态判定 −3、锁内复判 +4）。
> 写法对比（4 任务：2 个 Yield + 2 个 `DelayMs(1)`，单位 = 往返周期；两列分别为 Yield / Delay 路径）：
> 锁外判定无复判 **1273 / 1274**、**锁外快判 + 锁内复判 1281 / 1282（采用）**、锁包判定 **1293 / 1294**。
> 语义：`ListNode` 在任务被移除后置 `NULL`（不再保留"自环"）⇒ "自环"唯一表示"游离待归位"；已移除节点不得再被链表操作触碰。

> **RAM 证据**：`stats` 档 `ZI` 增量 **+96 B = 12 个 TCB × 8 B** ⇒ 与"每任务 +8 B"的设计完全吻合。
> **示例侧观测变量**：`stats`/`diag` 档 `RW` **+16 B** —— 示例 `main.c` 的诊断演示新增 4 个 `volatile` 观测变量
> （`s_DiagChkLast` / `s_DiagChkTimes` / `s_DiagRunCnt` / `s_DiagMaxRunTick`，**仅开关打开时存在**）；
> `default` 档 `Code/RO/RW/ZI` **全 0 漂移** ⇒ 佐证"关档连调用都不编译"。

> **口径说明（重要）**：`stats` 档只加开关；**示例里的诊断演示（`Idle()` → `DiagDemo()`）与观测变量只在开关打开时编译**（`default` 档 0 漂移即证）。
> 因此 `stats` 档相对 `default` 的增量 = 内核埋点 + 示例演示：**Code +152 B**、`RW +16 B`（示例 4 个观测变量）、`ZI +96 B`（12 × TCB +8 B）。
> 历史备注：若在示例 `main.c` 里**手工插入**调用做测量，**行号变化还会额外影响 Code**（示例任务用 ANSI 协程，断点常量取 `__LINE__`）：曾测得 `+104 B`（手工注入）；以本通道口径为准。

### 4.1 让出路径往返（补充测点，`Tests/run_yield.ps1`）

**测点**：`Tests/bench/xc_yield_bench.c`（4 个任务：**2 个纯 `Yield`** + **2 个 `DelayMs(1)`**；Tick 源每读 +1 ⇒ 不需要中断/外设）；
**口径**：各自"上次被调度 → 本次被调度"的**平均周期**（含 2 次计时读与调度器固定开销）⇒ **仅用于同口径对比**（绝对值含 4 任务轮转开销）。

| 指标（基线 key） | 周期 | 对应"归位判定"路径 |
| --- | --- | --- |
| `yield_roundtrip` | **1281** | 纯 `Yield` 任务 ⇒ 归位走"**自环**"路径 |
| `delay_roundtrip` | **1282** | `DelayMs(1)` 任务 ⇒ 归位走"**非自环**"路径 |

> **变更史（同口径，2026-09-16 归位判定改造）**：
> ① 改造前（锁外判定 + 无复判）：**1273 / 1274**；
> ② **改造后（锁外快判 + 锁内复判）＝上表 1281 / 1282** ⇒ 每次让出约 **+2 周期**（换来并发窗口关闭）；
> ③ 对照写法（锁包判定：锁内单次判定）：**1293 / 1294** ⇒ 更贵且每轮都持锁（ISR 更易退化为"只登记"）⇒ **未采用**。
> **用法**：`powershell -File Tests/run_yield.ps1`；重建基线顺序：先 `run_cycles.ps1 -WriteBaseline`，再 `run_yield.ps1 -WriteBaseline`
> （后者只合并这两个键）；`run_all.ps1` 已按 "channel 3 → 3b" 串好。
