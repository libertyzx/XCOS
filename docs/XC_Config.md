## 🚀 快速配置

默认配置已针对大多数应用场景优化, 开箱即用;

如需自定义, 请在工程中或者包含 `XCOS.h` 前定义相应宏;

```c
// 在包含 XCOS.h 前自定义配置
#define XC_CFG_MAX_TASKS        32      // 修改最大任务数
#define XC_CFG_TICKS_PER_SEC    1000    // 修改Tick频率

#include "XCOS.h"
```

## ⚙️ 配置参数

| 参数名称              | 类型  | 默认值            | 范围      | 说明              |
| ---                   | ---   | ---               | ---       | ---               |
| XC_Tick_t             | 宏    | uint32_t          | -         | 时间计数基础类型  |
| XC_CFG_MAX_TASKS      | 宏    | 100               | 10~255    | 最大任务数量      |
| XC_CFG_TICKS_PER_SEC  | 宏    | 1000              | 1~1000000 | 系统Tick频率(Hz)  |
| XC_SYS_TICK_COUNT     | 宏    | g_SysTickCount    | -         | 系统Tick计数变量  |

## 📋 参数详解

### 🔧 XC_Tick_t - 基础数据类型

**用途:** 所有时间计数相关的变量类型;

**说明:**
- ✅ 用于系统滴答计数, 延时时间等所有时间相关变量
- ✅ 默认 uint32_t, 可支持约49天的连续计数(1ms Tick)
- ✅ 一般无需修改, 保持默认即可

### 🎯 XC_CFG_MAX_TASKS - 最大任务数

**用途:** 限制系统支持的最大任务数量

**说明:**
- ✅ 只限制最大能注册的任务;
- ✅ 任务只会在注册的时候占用资源, 任务数量不会影响框架占用的资源大小;
- ✅ 协作式调度中, 任务数过多会影响实时性;

### ⏱️ XC_CFG_TICKS_PER_SEC - 系统Tick频率

**用途:** 定义系统时间基准精度

**频率选择参考:**

| 频率值    | 周期  | 适用场景              |
| ---       | ---   | ---                   |
| 100Hz     | 10ms  | 响应要求低            |
| 1kHz      | 1ms   | **通用应用**(默认)    |
| 10kHz     | 100us | 高精度定时需求        |
| 100kHz    | 10us  | 极高精度需求          |

### 🔄 XC_SYS_TICK_COUNT - 系统Tick计数

**用途:** 系统时间基准的计数变量

#### 🔧 滴答计数实现

XCOS支持两种滴答计数实现方式:

#### 方式1: 中断累加模式(默认)

推荐用于大多数应用

**实现步骤:**
1. 配置硬件定时器, 频率为 XC_CFG_TICKS_PER_SEC
2. 在定时器中断中调用 XCTime_TickInc()

#### 方式2: 直接计数器模式

推荐用于性能要求极高的应用

**实现步骤:**
1. 配置硬件定时器为计数器模式
2. 将 XC_SYS_TICK_COUNT 映射到计数器寄存器

**性能优势:**
- ⚡ 零函数调用开销
- ⚡ 直接读取硬件计数器
- ⚡ 适合高频Tick应用

**注意事项:**
- 🔧 需要32位硬件计数器
- 🔧 注意寄存器访问权限(volatile)
- 🔧 确保计数器溢出后会从0开始计数
