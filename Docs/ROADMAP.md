## ✅ v2.1.0 已完成 - 协程嵌套 + MISRA 合规

### 已完成事项

| 事项 | 说明 | 状态 | 完成日期 |
| :--- | :--- | :--- | :--- |
| **MISRA C 2025 合规检查** | 修复全部 Required 规则违规，统一代码与注释格式，Advisory 项记录 Deviation（详见 `Docs/MISRA-C/`） | ✅ 完成 | 2026-08-14 |
| **协程嵌套（帧栈 + 多级调度）** | 帧栈实现子协程调用/返回，C 栈开销恒定 O(1)，调度器支持"同轮切父" | ✅ 完成 | 2026-08-20 |
| **ANSI 底层缺陷修复** | `goto` 误改为 `break` 导致循环体内挂起失效，已回退 `goto` 并恢复 `COR_GOTO_END` 标签 | ✅ 完成 | 2026-08-20 |
| **内核缺陷修复（8 项）** | 通知改「待处理标志」（消除 `uint8_t` 计数回绕导致的丢唤醒）、挂起优先级最高、**入就绪表统一排队尾**（严格轮转）、重复注册检测、非因子频率/Tick 宽度**编译期断言**、`>1000 Hz` 换算修正等；详见 `Docs/CHANGELOG.md`「T2026/09/16」 | ✅ 完成 | 2026-09-14 |
| **诊断能力 + 回归基线（工程化）** | 新增 `Code/Inc/XC_Err.h`（错误上报：错误码 + 用户钩子）与 `XC_Diag.h`/`XC_Diag.c`（断言 / 运行期自检 / 运行统计，**默认关 ⇒ 0 代码·0 RAM**）；新增 `Tests/` —— **一条命令自测「功能 / 体积 / 速度」三件事**（`powershell -File Tests/run_all.ps1`） | ✅ 完成 | 2026-09-14 |
| **复核修正与规则固化** | 「断言 vs 返回码」边界规则（**单一强制点**）+ 全仓去重；文档与代码同步（架构概览/API 手册/配置/示例/MISRA） | ✅ 完成 | 2026-09-15 |
| **空闲 Tick 计算缺陷（A17）** | 空闲提示值 `IdleTick` 的"已过点下溢"（`fIdle` 收到 `0xFFFFFFFF`）与"陈旧快照"（中断搬表 ⇒ 表根当 TCB 读）：**锁内取值**（"就绪表是否空"与"最近唤醒时刻"同一次原子观察）+ **已过点钳位为 0**（仅动空闲分支，实测镜像 **+48 B**、RAM 0）；方案 + 确定性复现用例见 [`Docs/问题跟踪/修正方案/20260916_A17_空闲Tick钳位与取值纪律/`](./问题跟踪/修正方案/20260916_A17_空闲Tick钳位与取值纪律/修正方案.md) | ✅ 完成 | 2026-09-16 |

## 🗺️ v2.2 计划 - 功能增强

以下功能均为**规划中，尚未开始**，将视社区反馈决定优先级与推进节奏。

### 软件定时器增强

| 事项 | 说明 |
| :--- | :--- |
| 动态定时器 | 支持定时器的创建/删除，摆脱当前 `XC_TimerTick_t` 静态类型 |
| 一次性/周期定时模式 | 支持一次性与周期两种触发模式 |
| 定时器回调 | 定时器到期后回调用户函数 |

### 其他方向（评估中）

| 事项 | 说明 |
| :--- | :--- |
| 内存池/内存管理 | 为动态任务注册与嵌套帧栈提供内存池分配 |
| 事件标志组 | 在 SPSC 通知基础上的多事件同步机制 |
| 静态代码分析接入 | 配置 PC-lint / Clang-Tidy 并纳入 CI |
| **兼容层收尾（V2.2.0）** | 删除 `XC_Compat.h`（旧名 `XC_*` 协程宏 / `XCTask_*` / `XCSch_*` / `XCTime_*`）——**破坏性变更**，须附迁移指引；见 `Docs/XCOS.md`「🔁 向后兼容」弃用策略 |
