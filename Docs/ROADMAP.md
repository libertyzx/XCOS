## ✅ v2.1.0 已完成 - 协程嵌套 + MISRA 合规

### 已完成事项

| 事项 | 说明 | 状态 | 完成日期 |
| :--- | :--- | :--- | :--- |
| **MISRA C 2025 合规检查** | 修复全部 Required 规则违规，统一代码与注释格式，Advisory 项记录 Deviation（详见 `Docs/MISRA-C/`） | ✅ 完成 | 2026-08-14 |
| **协程嵌套（帧栈 + 多级调度）** | 帧栈实现子协程调用/返回，C 栈开销恒定 O(1)，调度器支持"同轮切父" | ✅ 完成 | 2026-08-20 |
| **ANSI 底层缺陷修复** | `goto` 误改为 `break` 导致循环体内挂起失效，已回退 `goto` 并恢复 `COR_GOTO_END` 标签 | ✅ 完成 | 2026-08-20 |

### v2.1.0 遗留/说明

- ANSI 版协程底层（`XC_CorANSI.h`）自嵌套功能起使用 `goto COR_GOTO_END`（前向跳转 cleanup 模式），与 GNU 版一致，纳入 MISRA Rule 15.1 Deviation（DEV-XCOS-001）；
- `XC_Compat.h` 向后兼容宏仍在（旧名 `XC_*`/`XCSch_*`/`XCTask_*`/`XCTime_*`），后续版本将删除，新代码请使用新命名。

## 🗺️ v2.2 计划 - 功能增强

以下功能均为**规划中，尚未开始**，将视社区反馈决定优先级与推进节奏。

### 软件定时器增强

| 事项 | 说明 |
| :--- | :--- |
| 动态定时器 | 支持定时器的创建/删除，摆脱当前 `XC_TimerTick_t` 静态类型 |
| 一次性/周期定时模式 | 支持一次性与周期两种触发模式 |
| 定时器回调 | 定时器到期后回调用户函数 |

### 其他方向（评估中）

| 事项 | 说明 |
| :--- | :--- |
| 内存池/内存管理 | 为动态任务注册与嵌套帧栈提供内存池分配 |
| 事件标志组 | 在 SPSC 通知基础上的多事件同步机制 |
