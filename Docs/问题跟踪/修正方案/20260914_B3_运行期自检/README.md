> **条目**：[`Docs/问题跟踪/问题清单/20260914_诊断能力与工程化.md`](../../问题清单/20260914_诊断能力与工程化.md)（✅ 已修复）

## 做了什么

新增**调试用**运行期自检函数 `XC_Diag_CheckInvariants(phXCOS)`（开关 `XC_CFG_DEBUG_CHECK`，**默认关**）：
把「四张任务表 + 每个任务的状态标签」盘点一遍，检查内核依赖的不变量是否仍成立，返回 `XC_CHK_OK` 或**第一个失败项编号**。

| 文件                   | 内容                                                                                                           |
| ---------------------- | -------------------------------------------------------------------------------------------------------------- |
| `Code/Inc/XC_Config.h` | 开关 `XC_CFG_DEBUG_CHECK`（默认 `0`）                                                                          |
| `Code/Inc/XC_Sch.h`    | `XC_ChkResult_t` 枚举 + `XC_Diag_CheckInvariants()` 声明（仅开关打开时编译）                                   |
| `Code/Src/XC_Sch.c`    | 实现（四表遍历 / 状态↔表 / 双向指针 / 重复挂表 / `TaskNum` / 嵌套不变量；带步数上限防环；全程短暂持锁；只读） |

**检查项 → 失败码**：状态↔表不符 = `2`；链表损坏/成环 = `1`；重复挂表 = `3`；`TaskNum` 不符 = `4`；嵌套不自洽 = `5`；任务归属错 = `6`。

## 怎么在工程里用

```c
#define XC_CFG_DEBUG_CHECK (1U)   /* 调试档; 发布档不定义 */
#include "XCOS.h"

/* ① 回归用例: 每个 API 调用之后 */
/* ② 运行期守护: 空闲回调里每隔 N 轮 */
/* ③ 排障: 可疑点手工插入 */
XC_ChkResult_t rc = XC_Diag_CheckInvariants(&g_xc);
if(rc != XC_CHK_OK) { /* 记日志 / 点亮指示灯 / 调 XC_Err_Hook */ }
```

> 注意：自检内部**短暂持锁**，不可在已持锁的上下文调用；开关关闭时该函数**不编译**（调用点用 `#if` 包住）。
