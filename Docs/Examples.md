## 📊 资源占用分析

### 内存占用对比表 (MDK -O0)

| 配置      | Code  | RO-data   | RW-data   | ZI-data   | Flash增量     | RAM增量       |
| ---       | ---   | ---       | ---       | ---       | ---           | ---           |
| **基准**  | 4716  | 380       | 28        | 1172      | -             | -             |
| **配置1** | 5404  | 380       | 28        | 1220      | +688 Bytes    | +48 Bytes     |
| **配置2** | 7632  | 380       | 40        | 1712      | +2928 Bytes   | +552 Bytes    |

- 注:增量为和基准比较的值;

### 资源占用总结

基于上述测试数据，XCOS框架的资源占用特点如下:

- **框架核心**: 约 **690 Bytes Flash** + **48 Bytes + 4 Byte RAM**
- **单个任务**(10任务)平均: 约 **230 Bytes Flash** + **36 Bytes + 其他 RAM**

**资源效率**: 每个新增任务仅增加约230字节Flash和36字节RAM，适合资源受限的嵌入式环境。

## ⚙️ 示例配置说明

### 配置0 - 基准测试
**用途**: 建立无框架代码的内存占用基准
- 无任何XCOS框架函数和变量(注:文件内有4Byte的全局变量)
- 仅包含基础硬件初始化和HAL库

### 配置1 - 框架核心
**用途**: 测试框架核心开销
- 1个框架句柄 (`XC_OSHandle_t`)
- 嘀嗒中断调用 `XCTime_TickInc()`
- 框架初始化和启动

### 配置2 - 完整功能测试
**用途**: 全面测试框架所有功能
- 10个不同功能的任务
- 涵盖所有API和中断操作
- 包含空闲回调处理
